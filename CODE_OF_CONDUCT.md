# Code of Conduct

Be respectful, assume good faith, and keep discussion focused on the
project. Personal attacks, harassment, or discriminatory language aren't
welcome here.

Disagreements about code should be settled with evidence (tests,
benchmarks, reproduction steps) rather than assertions. If a discussion
turns unproductive, a maintainer may close or lock it.

Report conduct concerns by opening a private security advisory or
contacting the repository owner directly — not in a public issue.
